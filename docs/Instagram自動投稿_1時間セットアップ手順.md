# Instagram 自動投稿を1時間で作る手順（Claude Code 初心者向け）

**対象**: Claude Code をこれから使う初心者
**所要時間**: 約60分
**ゴール**: Instagram に画像カルーセルが週3回、自動で投稿される状態にする
**費用**: 無料（AIの文章生成もClaudeがやるので有料APIキーは不要）

---

## 🧭 最初に覚える大原則（これだけで9割うまくいく）

1. **Claude Code には「日本語で普通にお願いするだけ」でいい。** コマンドは覚えなくてよい。
2. **Claude が代われない作業は3つだけ。ここは自分でやる:**
   - パスワード入力・**ログイン**
   - 「**許可**」ボタン（OAuth同意）
   - 規約への同意・**アカウント作成**
3. **詰まったら、画面のエラーをそのまま貼って「これ直して」と言えばいい。** Claudeが原因を調べて直す。

---

## 📦 Step 0：始める前に用意するもの（5分）

- **Instagram のプロアカウント**（ビジネス or クリエイター。個人アカウントはAPI不可）
- **GitHub アカウント**（無料。無ければこの場で作る）
- Claude Code が動く PC

> Instagramがプロアカウントか分からないときは、最初にこう頼む:
>
> ```
> 私のInstagram（@ユーザー名）がプロアカウントか確認して。違えば切り替え方を教えて。
> ```

---

## ⏱ 時間配分（合計約60分）

| Step | 内容 | 時間 | 主に誰が |
|------|------|------|----------|
| 1 | コードを用意 | 5分 | Claude |
| 2 | **Instagram APIトークン取得** | 20分 | 本人＋Claude |

> 一番時間がかかり、初心者が詰まりやすいのは **Step 2**。ここを丁寧に。

## 🛠 Step 1：コードを用意する（5分・ほぼClaudeがやる）

ゼロから作ると数時間かかるので、**完成済みのコードをコピーして使う。**

**プロンプト（そのまま貼る）:**

```
Instagramカルーセルの自動投稿システムを作りたいです。
https://github.com/hase-1/insta-auto-post に完成品があるので、
これをベースにして、私のPCにコピーしてセットアップしてください。
仕組みは「HTMLテンプレートで画像を作り、GitHub経由で公開URL化して、
Instagram Graph APIでカルーセル投稿。GitHub Actionsで週3回自動実行」です。
まず全体像を説明してから進めてください。
```

Claudeがコードを配置し、`npm install` まで済ませる。ここは見ているだけでOK。

> 自分の別アカウントで使う場合は、続けてこう頼む:
>
> ```
> 投稿するのは @自分のユーザー名 です。キャプションの固定文やハッシュタグを
> 私のアカウント用に書き換えてください。
> ```

---

## 🔑 Step 2：Instagram APIトークンを取る（20分・ここが山場）

**プロンプト:**

```
Instagram投稿用のアクセストークンとユーザーIDを取りたいです。
Meta for Developers の画面を開いて、1ステップずつ案内してください。
ログインや「許可」など私がやる部分は、その都度指示してください。
```

Claudeが画面を開いて案内する。**本人がやるのは次の5箇所だけ**（Claudeが「ここ押して」と言う）:

1. Metaにログイン
2. アプリに `instagram_business_content_publish` 権限を追加（Claudeが場所を示す）
3. **アカウントを「Instagramテスター」として追加 → Instagramアプリ側で招待を「承認」**
4. 「トークンを生成」→ ログイン＆許可
5. 出てきた**トークンを `.env` ファイルに貼る**（チャットには貼らない）

> ⚠️ **最重要**: 手順3の「テスター招待の承認」を忘れると
> **「開発者の役割が不十分」エラー**になり、そこで止まる。一番多いつまずき。
> Instagramのアプリ（または設定 > アプリとウェブサイト > テスターへのご招待）で
> **本人が「承認」を押す**必要がある。

> 詰まったときのプロンプト:
>
> ```
> 「開発者の役割が不十分」と出ました。どうすればいい?
> ```

---

## 🐙 Step 3：GitHub連携（15分）

画像の公開とcron自動実行にGitHubを使う。

**プロンプト:**

```
GitHubリポジトリを作って、コードをアップして、自動実行の設定までしたいです。
案内してください。リポジトリはpublicにする必要があるんですよね?
```

本人がやること:

1. GitHubにログイン
2. Claudeの案内で **publicリポジトリを作成**（画像を公開URLで取るため public 必須）
3. **個人アクセストークン(PAT)を1つ作成** → `.env` に貼る
   （Claudeが作成ページのURL・必要なスコープ `repo`・有効期限を教える）

**PATを貼ったら:**

```
PATを.envに貼りました。gh CLIで必要なSecretsを全部登録してください。
```

> PATを1つ貼れば、あとはClaudeが `gh` コマンドで
> **GitHub Secrets（IG_ACCESS_TOKEN など）を自動登録**する。ここは全部Claude。

---

## ✍️ Step 4：投稿ネタを作る（5分・全部Claude）

**プロンプト:**

```
投稿の在庫を8本作ってください。テーマは「IT初心者向けのオンライン起業サポート」で、
既存の投稿と重複しないように。作ったらキューに入れてGitHubにpushして。
```

Claudeが画像7枚×8本とキャプションを生成してコミットする。
**文章も画像もClaudeが作るのでAPI不要・無料。**

---

## 🚀 Step 5：テスト投稿して確認（10分）

**プロンプト:**

```
実際に1本、テスト投稿してちゃんと動くか確認してください。
投稿されたらInstagramのリンクを教えて。
```

Claudeがワークフローを手動実行し、実際に1本公開してリンクで確認できる。
ここまで来れば **あとは月・水・金に自動で投稿**される。

**放置できるようにする仕上げ:**

```
在庫が減ったら自動でメール通知が来るようにして。
それと、今後の注意点（トークンの有効期限など）を教えて。
```

## 🔧 運用（作ったあと）

- **普段は完全放置。** 月・水・金12時に自動投稿される。
- **在庫が残り3本になると、日曜に自動でメール通知が届く。**
  来たら Claude に「**インスタの在庫を補充して**」と頼めば、また8本足してくれる（約1分・無料）。
- **トークン(PAT)は90日で失効する。** 切れると投稿が徐々に止まるので、その頃に
  「**GitHubトークンを作り直したい**」と頼んで更新する。

## 💡 つまずいたとき共通の魔法の言葉

```
今こういうエラーが出ています：（画面の文字をそのまま貼る）
原因を調べて直してください。
```

Claude Code は、エラーの原因調査から修正まで自分でやってくれる。
分からないことは遠慮なく日本語で聞けばよい。
