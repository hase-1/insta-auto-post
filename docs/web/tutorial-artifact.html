Claude Code ではじめる

Instagram 自動投稿ガイド

専門知識ゼロでも大丈夫。青いカードを Claude Code にコピペして、指示された所を押していくだけで、自分の Instagram が週3回、自動で投稿されるようになります。

💰 無料 ⏱ 約60〜90分 🔰 初心者OK 🤖 画像も文章もAIが作成

🗺 このガイドの記号（最初に読んでください）

📋 濃い青のカード  = ここを丸ごとコピーして、Claude Code に貼り付ける 部分です。右上の「コピー」ボタンでコピーできます。（文中のオレンジ色の部分だけ、自分の内容に書き換えてから貼ります）
🙋 あなたがやる  = あなたが自分で操作する 部分（ログイン・「許可」ボタンなど）。ここだけは Claude が代われません。
⚠️ 注意  = 特につまずきやすい所。飛ばさないでください。

はじめに：3つの大原則

これだけ頭に入れておけば、9割うまくいきます。

1

日本語で普通にお願いするだけ。 コマンドや専門用語は覚えなくてOK。このガイドの青いカードをコピペするだけです。

2

Claude が代われない作業は3つだけ。 ①ログイン（パスワード入力）②「許可」ボタン ③規約への同意・アカウント作成。ここは自分で操作します。

3

困ったら、そのまま伝えればいい。 「エラーが出た（画面の文字を貼る）」「どうすればいい?」で、Claude が調べて直します。うまくいかなくても壊れません。

02

Instagram APIトークンを取る

約25分 ・ ここが一番の山場

投稿するには「Instagramに投稿していい」という許可証（トークン）が必要です。Claude が画面を開いて案内してくれます。

📋 これをコピーして Claude Code に貼る
Instagram投稿用のアクセストークンとユーザーIDを取りたいです。Meta for Developers で開発者用アプリを新規作成するところから、画面を開いて1ステップずつ案内してください。ログインや「許可」など私がやる部分は、その都度はっきり指示してください。

🙋 あなたがやる操作（Claudeが「ここ押して」と言います）

  • Meta（Facebook）にログインし、開発者登録に同意（初回のみ）
  • アプリを新規作成（用途は「Instagram」を選ぶ）
  • instagram_business_content_publish 権限を追加
  • 自分のInstagramを「テスター」として追加 →「承認」
  • 「トークンを生成」→ Instagramにログイン＆「許可」
  • 出てきたトークンを .env ファイルに貼る（チャットには貼らない）

⚠️ 一番多いつまずき：テスター招待の「承認」

「テスター」に追加しただけでは足りません。Instagramアプリの「設定 › アプリとウェブサイト › テスターへのご招待」で、自分で「承認」ボタンを押す必要があります。忘れると「開発者の役割が不十分」エラーで止まります。詰まったら次を貼ってください。

📋 「開発者の役割が不十分」と出たとき
「開発者の役割が不十分」と出ました。どうすればいい?
03

GitHub連携（画像の公開と自動実行）

約15分

画像をネット上に公開したり、決めた曜日に自動で投稿するために GitHub を使います。

📋 これをコピーして Claude Code に貼る
GitHubを使って、画像の公開と自動実行の設定をしたいです。GitHubアカウントの用意から、リポジトリ作成、コードのアップ、自動実行の設定まで、1ステップずつ案内してください。

🙋 あなたがやる操作

  • GitHubにログイン（アカウントが無ければ、この場で無料作成）
  • 案内に従って public のリポジトリを作成（画像をネットから取得できるようにするため）
  • 個人アクセストークン（PAT）を1つ作成 → .env に貼る（Claudeが作成ページと設定を教えます）
📋 PATを貼ったら、これを貼る
PATを.envに貼りました。必要な設定（Secrets）を全部登録してください。
04

自分のテーマで投稿ネタを作る

約5分 ・ 全部 Claude がやります

画像も文章も Claude が作ります。追加費用はゼロです。

📋 これをコピーして Claude Code に貼る（テーマを自分の内容に）
投稿の在庫を8本作ってください。テーマは「あなたの発信テーマ（例：パン教室の集客のコツ）」で、内容が重複しないように。作ったら投稿キューに入れてGitHubにアップして。

💡 仕上がりが気に入らないとき

「もっとやさしい雰囲気にして」「この言葉を変えて」など、日本語で注文すれば何度でも作り直せます。

05

テスト投稿して確認

約10分

実際に1本だけ投稿して、ちゃんと動くか確認します。ここまで来れば、あとは自動で定期投稿されます。

📋 これをコピーして Claude Code に貼る
実際に1本、テスト投稿してちゃんと動くか確認してください。投稿されたらInstagramのリンクを教えて。
📋 仕上げ（頻度の変更＋在庫切れ通知）
投稿の頻度と曜日を私の希望に変えたいです。（例：火・金の朝8時） それと、在庫が減ったら自動でメール通知が来るようにして。今後の注意点（トークンの有効期限など）も教えてください。

よくある質問

プログラミングの知識は要りますか?

要りません。このガイドの青いカードをコピーして貼り、指示された所を押すだけです。

お金はかかりますか?

かかりません。画像も文章も Claude が作るので、有料のAIキーは不要です。GitHubもMetaも無料の範囲で使えます。

途中でやめて、あとで続けられますか?

できます。次に開いたとき「今どこまで進んだか確認して」と頼めば、Claude が現状を見て続きを案内します。

投稿内容は自分で決められますか?

はい。テーマを伝えれば Claude が作りますし、「この部分をこう変えて」と何度でも直せます。

青いカードをコピーして Claude Code に貼る → 指示された所を押す → トークンを .env に貼る。この繰り返しだけで、自分のアカウントの自動投稿が完成します。うまくいかなくても壊れないので、安心して進めてください。
